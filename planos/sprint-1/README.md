# Sprint 1: Fundamentos e Estrutura (2 dias)

## Objetivo

Configurar estrutura do projeto e banco de dados seguindo DDD e normalização

## Visão Geral

Esta sprint estabelece os fundamentos técnicos do projeto, incluindo:

- Configuração inicial do projeto
- Estrutura de pastas seguindo Feature Folders
- Modelagem de dados com 3FN e trigramação
- Implementação da camada de persistência
- Configuração de segurança do banco de dados (RBAC)
- Configuração de PostgreSQL via Docker

## Contexto

Esta sprint é crítica pois estabelece a base técnica sobre a qual todas as outras sprints serão construídas. Uma estrutura sólida desde o início facilita o desenvolvimento futuro e mantém a consistência com os princípios de Domain-Driven Design.
